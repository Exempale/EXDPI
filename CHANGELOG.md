# EXDPI — что изменено в этой сборке

Дата сборки: по запросу timur.mainkraft.

## 1. VPN больше не рубит интернет (критический фикс)
Файл: app/singbox_config.py
- **Первопричина**: `route.default_domain_resolver` был `dns-remote`, а
  `dns-remote` ходит через прокси. Чтобы поднять туннель к серверу по имени,
  sing-box должен резолвить имя — но резолвер идёт через ещё-не-поднятый
  туннель → циклический тупик → TUN `final` становится чёрной дырой →
  интернет пропадает целиком. Теперь `default_domain_resolver = "dns-direct"`.
- Добавлено правило `hijack-dns` (перехват системных DNS в TUN).
- Убран несуществующий в sing-box 1.13 outbound `{"type":"block"}`
  (ломал парсинг конфига в бандле 1.13.14).
- MTU 9000 → 1500 по умолчанию (jumbo MTU давал чёрные дыры на пакетах),
  strict_route true → false по умолчанию, stack gvisor → mixed.

Про «пинг серверов»: он настоящий (прямой TCP-connect к server:port, не через
туннель). А обычный ICMP-ping под VPN не работает в принципе — VLESS/SS/VMess/
Trojan переносят только TCP/UDP, не ICMP. Проверяйте доступ браузером или
тестом обхода, а не `ping`.

## 2. Флаги стран — теперь почти все
Файлы: app/countries.py (новый), app/singbox_config.py, app/widgets.py
- Единая таблица стран `app/countries.py`: **98 стран**, 312 вариантов
  написания (коды/русские+английские названия/алиасы/эмодзи-декод) и
  векторная отрисовка флага на Canvas.
- `guess_country_code` и `_draw_flag` теперь работают из этой таблицы —
  раньше было ~20 стран, для остальных флаг не рисовался вообще.

## 3. Размер окна VPN
Файл: app/ui_app.py
- Отдельная геометрия под режим: VPN-окно выше и шире (460×760, мин 420×620),
  чтобы список серверов, поле ссылки, тоггл, статус и баннер помещались;
  DPI-окно осталось компактным (400×440). Высота ограничена высотой экрана.
- Применяется и при переключении режима/темы.

## 4. Настройки разделены на вкладки DPI / VPN / Общее
Файл: app/ui_settings.py
- **DPI**: стратегия (+авто-подбор), режим запрета, порт/хост/секрет, свои
  домены + готовые листы, защищённый DNS (DoH/DoT, провайдер, системный DNS).
- **VPN**: DNS-провайдер в туннеле, сетевой стек (Mixed/gVisor/System),
  MTU, «Россия напрямую», блокировка QUIC, IPv6, авто-выбор быстрейшего
  сервера, kill-switch (strict route).
- **Общее**: автозапуск, трей, запуск свёрнутым, уведомления, тема,
  режим разработчика.
- По умолчанию открывается вкладка текущего режима приложения.

## 5. Новые полезные VPN-настройки (и их проброс в рантайм)
Файлы: app/config.py, app/singbox_config.py, app/singbox_runner.py,
       app/controller.py
- Добавлены и валидируются ключи: vpn_dns, vpn_tun_stack, vpn_mtu, vpn_ipv6,
  vpn_strict_route, vpn_block_quic, vpn_ru_direct, vpn_autoselect_fastest.
- Значения реально доходят до генератора конфига: `controller` при старте VPN
  передаёт cfg → `singbox_runner.start(..., options=cfg)` →
  `save_config(..., options=...)` → `build_config`.

## 6. Косметика мастера первого запуска
Файл: app/ui_wizard.py
- Подъём кнопки «далее» при наведении, hover-подсветка карточек-вариантов,
  тонкая линия-трек под точками прогресса. Логика шагов не тронута.
